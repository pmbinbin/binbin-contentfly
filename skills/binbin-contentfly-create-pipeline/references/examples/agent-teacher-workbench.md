# 千问办公，一份名单变两个工作台

## 封面

不会代码
我用千问办公
做了个教师工作台！

保姆级教程！

## 发布标题

小白也能做！我给老师做了套教师工作台！解放琐事，秒变互动课堂！

## 口播稿

这是我用AI给我妈做的教师工作台。你看，手机上点一下王小明，班级大屏这边马上就会开始呼叫！我还做了排座位、管理成绩、批量写评语这些功能，甚至用的也都是前面这同一份学生名单。

我妈呢，是一名语文老师。她一直和我吐槽说，当老师真正耗时间的，不是站在讲台上的几十分钟，反而是管理学生、整理成绩、写评语、还有准备互动课堂。这些事情每一件都不难，但是叠在一起就又碎又烦人。

那么今天这期呢，我就来给大家看一下，我作为一个不懂代码的人，是怎么用千问办公，把这些东西做成一套教师工作台，并且部署上线的。老师们千万别被吓到了，真的有手就行！注意记笔记！

首先，我把学生名单和成绩表交给千问办公，然后跟它说，我需要一个教师工作台，里面要有班级管理、成绩管理、学生评语功能。

这里我还特意补了一句，因为我怕它最后只是给我做一张好看的演示页面。我跟它说，学生资料、座位和成绩都要保存在数据库里，也就是页面刷新以后，前面的数据还在。

我发送之后，可以看到千问办公先帮我拆解任务，然后帮我生成这整套工作台。

好，我们先来看教师工作台。这里先看班级管理。

老师可以建立多个班级，然后导入学生名单，记录学生的姓名和班干部职务。名单导入之后，这里还可以直接生成座位表。

比方说，我把座位设置成六乘八，再告诉它男生女生不能同桌，还有哪两位学生不能坐在一起，它就会按照这些条件随机去排。如果有哪个位置不太合适，老师也可以直接拖动名字，自己再调一下。

排完以后，还可以设置后面的轮换方式。比如说每隔两周，所有人往前移动一排，靠前这一排再换到后面。这样下一次换座位的时候，就不用老师重新一个个去排了。这个我觉得还是蛮实用的。

那么接下来呢，我们来看成绩管理。

我给它导入了一个班近四个月的语文成绩表。它会先检查学生姓名和月份能不能对上，然后把这些数据做成一个班级看板。这里可以看到每次考试的平均分、高分、低分，还有各个分数区间的人数，以及整个班这四个月的变化。

然后除了看整个班，也可以单独点进某一位学生。比方说这个A同学，我们就可以看到他四次语文成绩的变化曲线。老师还可以在旁边补充他的阅读、写作和日常表现，这样后面看这个学生的时候，就不只是看一张成绩单了。

有了前面这些信息以后，再来写学生评语就会方便很多。

老师可以先设置分组规则，再选一下评语的语气和长度。然后千问办公会根据学生的职务、成绩变化，还有老师自己补充的记录，批量写出一版评语初稿。比如说成绩比较稳定的学生，可以提醒他下一阶段往哪个方向努力；变化比较明显的学生，就把这次的具体变化和鼓励写进去。

当然了，这个评语生成完以后，老师还是要自己一条一条检查和修改。它主要是帮你先把初稿写出来，不能直接代替老师去判断一个学生。

好，教师工作台看完以后，我们再来看跟它联动的班级大屏，又是怎么做的！

这里我回到千问办公，继续和他用大白话说，帮我增加一个班级大屏端，里面要有学生叫号、随机点名器、音量提醒器功能。另外我还补了一句，教师工作台和班级大屏，也要能够实时联动。

最后它帮我分成了两个端，一个是之前的教师工作台，可以在手机或者电脑上使用；另一个就是放在班级电脑上的班级大屏。两个端读取的是同一份数据，所以学生名单只要导入一次就可以了。

我们来看看他做的大屏。首先就是刚才演示的学生叫号器。老师在手机上点一下某位学生，班级大屏这边就会弹出大字，同时播放语音：“请王小明同学到彬彬老师办公室来。”我觉得这个功能还蛮有意思的，老师不在班里的时候，就不用再临时找人帮忙传话了。

然后这里还有一个随机点名器。它会直接读取前面的学生名单，可以设置这一轮要不要重复。点名的时候，名字会在大屏上滚动，选中以后放大显示，旁边也会保留这一轮的记录。

再往下呢，是班级音量提示器。获得麦克风权限以后，它只会读取现在的音量大小，不会保存具体的声音。音量合适的时候，这棵小树是绿色的，而且会慢慢长大；如果超过老师设置的范围，它就会变成黄色或者红色，提醒大家把声音调小一点。

当然了，刚用AI做出来的时候也不是完全能用。当时教师工作台和班级大屏的入口有点分不清，而且大屏这边的按钮也太小了。所以我就继续跟千问办公说，把两个入口分开，把按钮放大，再给大屏加上一个配对状态。改完以后，整个操作就清楚很多了。

总之呢，我觉得用AI做这种工作台，重点就是你要把自己想要的功能和规则说清楚。比如说座位怎么排、哪些数据要保存、两个端要怎么联动。哪里做得不对，你就继续告诉它怎么改。

这次实测下来，千问办公让我觉得惊喜的点在于，他做出来的工作台并不只是一个壳，而是能真正部署上线，能在多端打开，并且能保存数据的！这样老师平常散在不同表格和页面里的这些事情，就可以放在同一套工作台里了。

## 制作备注

### 已验证功能与拍摄检查

- 用户已确认整套工作台能够跑通；拍摄时仍需录制千问办公拆解任务、生成、修改和部署的关键过程。
- 数据库：用刷新前后对比证明学生名单、座位和成绩仍然存在。
- 自动排座位：录制行列设置、性别限制、指定学生不相邻、手动拖动和轮换规则。
- 成绩看板：录制四个月表格字段对应、班级分布和个人曲线。
- 批量评语：展示评语确实读取了学生职务、成绩趋势和老师记录，而不是通用套话。
- 叫号器：完整录制教师工作台与班级大屏配对、推送、文字显示和语音播放。
- 音量提示器：录制麦克风授权、阈值变化和动画反馈。
- “10分钟”未写入口播；除非另有完整计时证据，否则不补回。
- 如果 qwen3.8 的使用和效果已有录屏证据，可在操作画面中补充型号；未确认则不写入口播。

### 建议重点录制的三个证据

1. 导入脱敏名单，设置六乘八座位、两个限制条件，再手动拖动一位学生并执行一次轮换。
2. 导入四个月虚拟成绩，依次展示班级分布看板、A同学个人曲线和基于多项数据生成的评语初稿。
3. 手机端点击一名学生，班级大屏实时显示并播报；随后展示不重复点名和音量变化反馈。

### 品牌审核检查

- 标题、封面、字幕和花字统一使用完整名称“千问办公”。
- 不出现其他AI平台名称、Logo、界面或网址。
- 不提阿里、钉钉内部管理相关内容。
- Logo使用品牌原图，不抠图、不改色、不描边。
- 整体保持真实、理性，不使用“一键搞定”“完全替代老师”等夸张表述。
- 开头不再借用其他创作者或产品热度，直接展示千问办公生成的双端联动结果。

### 隐私检查

- 学生名单、成绩、班干部职务、电话、学校和家长信息全部使用虚拟或脱敏数据。
- 音量提示器不录音、不保存声音内容，只读取实时音量值。
- 叫号录屏使用虚拟姓名，不展示真实学生身份。
- 不在公开页面展示班级真实成绩、座位和评语。

### 敏感词处理说明

- 根据[[视频违禁词合集]]，正文用“教学准备助手”替代“备课助手”。
- 用“班级互动”“随机点名器”替代“课堂随机点名器”。
- 用“班级音量提示器”替代“声音监督器”，避免“监控、监听”等高风险联想。
- 正文未使用“打开、搜索、下载、最好、绝对、万能”等高风险表达。
