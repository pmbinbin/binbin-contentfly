# 彬彬短视频结构模板

先判断内容主要属于哪一类，再选择一个主模板。模板描述的是信息推进，不是必须逐句照搬的格式。

## 模板一：Agent 教学／工作台搭建

适合：Agent、工作台、自动化系统、多页面应用、业务流程搭建。

1. **结果演示**：先展示成品最有感知的两三个能力，并指出它们的关联。
2. **真实人物和工作痛点**：说明为谁做、为什么做，把碎片任务说具体。
3. **本期任务与门槛**：今天搭什么、做到什么程度、普通人能否跟上。
4. **提交资料和总需求**：展示输入文件、数据和第一轮大白话要求。
5. **补充关键约束**：防止只生成演示壳，说明数据保存、权限、业务规则、联动或输出标准。
6. **Agent 拆解并生成**：快速交代过程，不长时间展示等待。
7. **逐模块验收**：每一模块按“场景 → 操作 → 规则 → 结果 → 评价”展开。
8. **数据复用与联动**：解释同一份数据怎样继续服务后续模块或另一端。
9. **人工判断边界**：说明哪些结果必须由人检查、修改或最终决定。
10. **扩展完整闭环**：展示第二端、第二角色或下游动作。
11. **真实问题与修改**：给出第一次生成的问题，以及怎样继续要求 Agent 调整。
12. **方法总结**：提炼目标、功能、规则、数据和验收标准要说清楚。
13. **实测结论**：评价必须对应前面已经展示的证据。
14. **互动与固定收尾**。

结构母句：

> 最终系统 → 谁为什么需要 → 交给 Agent 什么 → 怎样约束它 → 模块如何工作 → 哪里第一次没做好 → 怎样修正 → 人应如何定义和验收

语感参考：[examples/agent-teacher-workbench.md](examples/agent-teacher-workbench.md)

## 模板二：AIGC 创作教学

适合：AI 绘图、视频、音乐、数字人、视觉设计和创作工作流。

1. **失败结果提问**：列出两三个观众一眼能看懂的问题。
2. **效果对比**：立即展示改进版本，明确观看收益。
3. **重新诊断**：把问题从“模型不行”转向导演、设计、镜头、叙事或工作流判断。
4. **方法地图**：告诉观众接下来如何解决；数字结构只在天然适合时使用。
5. **方法一，建立基础关系**：普通版问题 → 调整后差异 → 工具操作 → 例子 → 小结。
6. **方法二，丰富表达层次**：比较不同选择，并解释各自承担什么作用。
7. **克制提醒**：效果不是越多越好，每个选择都要服务表达。
8. **方法三，组织完整作品**：从单个素材进入时间线、剪辑、节奏、声音和字幕。
9. **复述完整链路**：一句话串起前面的方法。
10. **创作者判断**：明确 AI 与人的分工。
11. **温和鼓励与固定收尾**。

结构母句：

> 为什么生成结果不好 → 好结果长什么样 → 真正缺的是哪种创作判断 → 分步骤改进 → 把素材组织成作品 → AI 和创作者如何分工

语感参考：[examples/aigc-filmora-long-video.md](examples/aigc-filmora-long-video.md)

## 模板三：商单场景故事／AI 工具实测

适合：品牌 brief 明确、产品功能需要进入真实故事的商单和工具实测。

1. **现场原话、冲突或结果**：让观众先进入一个真实工作瞬间。
2. **具体故事**：讲清楚谁在做什么、当时发生了什么、为什么会返工或失效。
3. **后果**：说明这个问题造成的时间、协作或决策成本。
4. **核心判断**：从故事中提炼“真正缺的是什么”。
5. **产品自然进入**：说明这一次换了什么记录或工作方法。
6. **核心功能完整演示**：用一个具体动作讲透操作、结果和价值。
7. **使用后的人的反应**：不是夸 AI，而是说明哪里终于不再麻烦。
8. **相邻场景扩展**：扩展到两三个同构场景，不重新另起故事。
9. **从信息到行动**：展示总结、清单、交付或下游动作。
10. **辅助能力和权益**：快速补充，不抢主线。
11. **从业者判断**：回到彬彬自己的经验与观点。
12. **回扣开头**：用开头问题、画面或原话完成闭环。
13. **具体互动与固定收尾**。

结构母句：

> 真实现场出问题 → 原有方法为什么不够 → 产品补上缺失环节 → 用结果证明 → 扩展到更广人群 → 回到最初问题

语感参考：[examples/commercial-yuanbao-recorder.md](examples/commercial-yuanbao-recorder.md)

## 大纲与拍摄脚本的边界

大纲描述每一段“为什么存在、讲什么、怎样承接”，不连续写演员动作和镜头调度。只有逐字稿确认后，才把内容拆成镜号、画面、口播、时长、备注和审批建议。
