# 公众号 Markdown 输出规范

本规范用于阶段 A 的待配图稿，也定义阶段 B 的素材门禁。

## 文章骨架

骨架必须跟随原逐字稿，不套固定章节数量。以下只是短工具稿的格式示例，不是内容扩写模板：

````markdown
---
title: 文章标题
author: 彬彬
source_script: 已发布视频逐字稿
article_type: 产品实测/工具教程/深度观点/商业案例/Vlog
status: 待配图
---

# 文章标题

> 从原稿提炼的一句开头判断或结果。

原稿开头经过最小书面化处理后的正文。

> **【视频 01｜最终效果｜原视频】**
> 要求：截取最能证明结果的完整动作，建议 20—35 秒。

## 原稿里的第一个主要阶段

保留原稿对应段落和操作顺序。

### 原稿本来就有的步骤

```text
原稿中真实存在、需要读者复制的提示词。
```

> **【配图 01｜输入与执行结果｜工具截图】**
> 要求：保留输入区和结果区，只标一个关键位置。

## 原稿里的下一个主要阶段

继续沿用原稿内容。只有原稿存在多项对应关系时，才使用表格。

## 原稿原有的总结判断

保留作者原来的结论和署名，删除视频平台专用口令。
````

章节标题使用自然中文；`gzh-design` 会在排版阶段自动生成章节编号和英文标签，因此 Markdown 不需要手写 `01｜WORKFLOW`。短稿通常只需要 2—4 个主章节。

正文媒体占位保持两行，详细的来源、制作方式、构图、标注、文章作用、隐私/版权和状态全部写入 `02-配图与视频清单.md`，不要在公开正文里展开成长清单。

## 语义标记

| 目的 | Markdown 写法 | 使用原则 |
|---|---|---|
| 章节 | `## 标题` | 主章节，通常 4–7 个 |
| 子章节 | `### 标题` | 步骤、技巧、问题 |
| 锚点重点 | `**文字**` | 全文少量使用，优先结论和关键数字 |
| 高亮 | `==文字==` | 关键洞察，不和加粗叠用 |
| 下划线 | `<u>文字</u>` 或 `++文字++` | 需要显式下划线时使用；后续排版还会逐段补关键词下划线 |
| 引言/提示 | `> 文字` | 开头引言、结论或短 Prompt |
| Prompt/代码 | 围栏代码块 | 长提示词、命令、路径、代码 |
| 图片/GIF | `![说明](路径)` | 素材补齐后替换占位块 |
| 表格 | Markdown 表格 | 精确对比和字段映射 |

## 媒体类型判断

### 工具截图

用于界面、设置、提示词、执行过程、真实结果、价格和活动规则。不能用 AI 生图替代事实证据；必须遮挡、裁切或模糊 Logo、品牌名、产品名、域名、水印和可识别账号。

### 原视频截帧

用于已有视频里的关键画面、动作节点、修改前后和最终效果。来源优先写真实文件；暂时没有文件时写明需补充的素材类型，不猜时间戳，也不把内容标成待测试或待验证。

### 前后对比图

使用同尺寸、同主体、同构图并排展示。说明左/右各是什么以及比较维度，避免拿不同案例硬做对比。

### AI 生图

只用于概念头图、章节过渡、没有真实画面的故事、匿名化场景和视觉统一。要求写明画面内容、风格、比例、文字处理和禁止项。不得伪造实测、客户现场、收入或产品界面。

```markdown
> **【配图 04｜一个账号背后的生产线｜AI 生图】**
> 要求：真实工作室纪实感，画面内不生成文字，不出现品牌 Logo 或虚构数据。
```

### 信息图

用于三个以上流程、角色、层级、分支或上下游关系。说明节点文案、连接方向、阅读顺序和比例。如果只是精确字段对比，优先用表格。

### GIF

用于很短且循环的操作、按钮反馈或前后变化。超过约 10 秒或需要声音、完整叙事时改用视频。

### 视频

用于动作、转场、声音、口型、人物一致性、完整流程或生成连续性。说明建议时长、来源、起止内容、封面和上传状态。


## 阶段 B 素材门禁

以下任一情况存在时，不能称为公众号发布终稿：

- 正文仍出现未处理的媒体占位或内部制作说明。
- 图片路径不存在，或使用临时占位 URL。
- 视频只有要求，没有已上传状态或明确后续手工步骤。
- 截图含账号、密钥、真实学生/客户资料、本地隐私路径。
- AI 生图被用来代替产品实测或事实证据。
- 表格数据没有来源或口径前后不一致。
- 标题、正文、元数据、媒体说明、图片、视频、表格或 HTML 中仍出现品牌、公司、产品、应用、模型、服务、Logo、水印、域名或竞品名称。
- 正文或检查文件中出现“待测试”“待验证”“效果仍需确认”“这是合作内容”或同类风险提示。

门禁通过后，把制作要求从公开正文移入清单，只保留真实图片/GIF、视频位置、图注和文章内容，再交给 `gzh-design`。
