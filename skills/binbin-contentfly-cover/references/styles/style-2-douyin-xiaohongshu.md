# 风格2：抖音小红书超大标题封面

用于抖音、小红书的 `3:4` 竖版封面，规格 `1080x1440`。核心是超大标题、全幅背景和右下真人，信息少但视觉冲击强。

## 固定元素

画面只能由以下四类元素构成：

1. **主标题**：必需。
2. **副标题**：可选，没有必要时不要硬加。
3. **全幅背景图**：必需，可由用户提供或 AI 生成。
4. **参考图1真人形象**：必需，保持同一人物并采用本次指定的表情和动作，最终以真人抠图式前景固定在右下角。

不得加入边框、顶部账号栏、左上或右上角标、分类标签、Logo、机器人、图标按钮、小字说明、圆角电脑界面框、悬浮卡片、菜单、贴纸、箭头、流程线或其他装饰组件。背景场景本身可以包含与主题直接相关的物体，但不能把物体做成独立装饰卡片或 UI 元素。

主标题字体也是固定识别元素：无论使用蓝紫、荧光绿还是渐变亮蓝，都必须采用下方规定的超大厚重硬边斜切黑体与黑色超厚描边结构，不得随色盘更换字体骨架。

## 构图蓝图

- 背景图全幅铺满到四边，不留外框，不套圆角容器。
- 上半区约 40%–48% 用于主标题。背景在标题后方使用黑色或深色渐变压暗，保证文字清楚，但不要出现独立标题框。
- 主标题一般 2–3 行，横向尽量铺满安全区，行距紧、字距略紧、错位堆叠。关键词最大，标题整体只做 `2°–5°` 的轻微右上倾斜或轻微透视，最大不超过 `6°`。不要做成明显对角线或夸张冲刺角度。
- 主标题是绝对第一视觉锤，视觉高度比风格1更大；在手机缩略图中必须一眼读完。
- 副标题可放在主标题下方，使用一条短而粗的强调色横条或直接使用较小粗体字，只允许一行。
- 背景主体放在中下区，画面可以是人物行动、真实空间、产品使用场景、抽象科技场景或结果画面。避免复杂拼贴和多窗口结构。
- 参考图1的人物保持身份一致，采用本次指定的表情与动作，以真人半身抠图式前景放在右下角。使用用户确认的“中等偏大”比例：包含肩膀、手臂和手持物在内，人物整体占画面宽度约 42%–52%、高度约 42%–52%；人物头顶大约落在画面高度 50%–58% 的位置，底部贴近画面底边。脸部清晰，作为最前景图层，不得遮挡主标题的关键字。
- 人物必须像封面主体，不能缩成右下角的小头像、小贴纸或远景人物。以用户确认的对比图左侧人物大小为准，禁止使用右侧过小比例。
- 人物边缘使用与本次强调色一致的 4–10px 亮色描边，并加轻微深色投影。不要再加白色粗贴纸边。
- 人物动作可以包含双手和一个直接相关的手持物，例如手机；手持物视为人物动作的一部分，不得再扩展成独立卡片或装饰组件。最终提示词直接写清新的身体方向、左右手动作和视线方向。

## 标题字体

- 固定使用绿色确认版中的字形系统：**超大、极粗、硬边、斜切、切角感强的综艺海报黑体**。字面饱满，笔画粗壮，转角锐利，横竖笔画末端带楔形或刀切缺口，具有明显力量感。
- 字符自身允许轻微前倾和切角动势，但整组标题的版式倾斜仍控制在 `2°–5°`，最大不超过 `6°`。区分“字形本身有斜切感”和“整组标题大角度旋转”，禁止后者。
- 固定描边层级：白色或强调色实心填充 → 黑色超厚外描边（1080px宽画面约 14–24px）→ 向右下偏移的黑色硬投影。描边必须连续、清楚、厚重，使每个字像独立剪影块从背景中弹出。
- 主标题不使用细白边、多彩描边、柔光描边或金属3D倒角。可以有极轻微冷色边缘高光，但不能削弱黑色粗描边。
- 白字与强调色关键词交替；更换色盘时只改变填充色和人物描边颜色，字体骨架、粗细、切角、黑色外描边和硬投影全部保持不变。
- 不使用圆润卡通字、普通方正黑体、细字体、书法字、宋体、渐变彩虹字、金属立体字或没有描边的扁平标题。
- 英文 `AI` 可作为超大关键词，但不要额外添加无关英文。

## 强调色预设

### A：蓝紫科技

- 背景：黑色、深海军蓝、深靛蓝。
- 标题：白色为主，关键词使用亮蓝、蓝紫或冷青紫。
- 人物描边：冷蓝紫。
- 适合：AI模型、Agent、效率工具、科技趋势、工作流。

### B：荧光绿色

- 背景：黑色、深灰、墨绿黑。
- 标题：白色为主，关键词使用荧光黄绿色，建议接近 `#B7FF00` 或 `#A8FF00`。
- 副标题条与人物描边：同一荧光绿色。
- 适合：强教程、硬核玩法、实测、避坑、结果展示。

### C：渐变亮蓝

- 背景：黑色、深海军蓝、深蓝黑，允许少量冷蓝环境光。
- 标题：白色为主，关键词使用从亮青蓝 `#22D7FF` 到清澈亮蓝 `#168BFF` 的小幅纵向或斜向渐变；渐变克制，不做彩虹渐变。
- 副标题：优先白色粗体，或使用同套青蓝渐变但降低亮度。
- 人物描边：亮青蓝到亮蓝的细微渐变光边。
- 适合：平台更新、模型实测、数据结果、AI视频、科技工具。

用户未选择色盘时，根据背景自动判断：传统灰蓝科技背景用 A；需要强冲击时用 B；背景为黑蓝、主题偏平台更新或数据结果时用 C。每张只使用一套强调色，不要混用。

## 人物表情预设

- **自然微笑**：嘴角轻微上扬，眼神看向镜头，亲切真实，不过度表演。适合教程、经验分享和方法说明。
- **张嘴震惊**：眼睛睁大，眉毛明显抬起，嘴巴自然张成圆形，呈现“看到意外结果”的真实惊讶感。适合反差、重大更新和“没想到”类标题。
- **认真讲解**：表情专注，嘴巴微张，像正在解释一个重要方法。适合教程、工作流和知识内容。
- **疑惑思考**：眉头轻微收紧，嘴唇自然闭合或微抿，带有“这靠谱吗”的疑问感。适合避坑、判断和问题类内容。
- **兴奋推荐**：眼神明亮，露出自然笑容，情绪积极但不过度夸张。适合工具推荐、实测结果和资源分享。
- **自信坚定**：目光直视镜头，轻微微笑或自然闭嘴，呈现“我已经验证过”的确定感。适合结论、经验和商业判断。
- **无奈吐槽**：眉毛轻抬，嘴角略微下压或苦笑，呈现真实的无奈感。适合踩坑、失败复盘和反常识内容。
- **根据标题自动选择**：根据标题语气和封面主题选择最匹配的表情。问号、重大结果、反差或“没想到”类主题优先使用张嘴震惊或疑惑思考。

所有表情都以“参考图1的人物五官特征，保持人物一致性和真人质感”为前提。最终提示词只描述必要的表情变化，不把具体真人改写成一组通用外貌标签，不额外扩写未经参考图确认的面部细节。

## 人物动作预设

- **指向左上标题**：身体略微转向画面左侧，一只手抬起，食指明确指向左上方主标题。
- **双手点赞**：双手在胸前竖起大拇指，动作完整自然。适合推荐、实测和结果展示。
- **双手打开讲解**：双手在胸前自然展开，掌心略微向上，像正在解释一个方法。
- **一手持手机、一手讲解**：一只手拿手机，另一只手自然展开或指向左上方标题。
- **托腮思考**：一只手自然托住下巴，身体略微前倾。适合疑问、判断和避坑内容。
- **举拳自信**：一只手在胸前轻微握拳，表达行动、突破和确定感。
- **摊手无奈**：双手或单手自然摊开，配合无奈、反差或踩坑类内容。
- **根据标题自动选择**：根据标题、表情和右下角构图自动选择合适动作。

最终提示词必须把动作写成可执行的空间关系：身体朝向、左手动作、右手动作和视线方向分别说明。动作应符合正常人体结构，肩膀、手臂、双手、手指和手持物完整自然。

## 表情与动作匹配规则

- 自然微笑：优先搭配双手打开讲解、一手持手机或指向左上标题。
- 张嘴震惊：优先搭配一手持手机、摊手无奈或指向左上标题。
- 认真讲解：优先搭配双手打开讲解或一手持手机、一手讲解。
- 疑惑思考：优先搭配托腮思考或摊手无奈。
- 兴奋推荐：优先搭配双手点赞、指向左上标题或举拳自信。
- 自信坚定：优先搭配举拳自信、指向左上标题或一手持手机。
- 无奈吐槽：优先搭配摊手无奈或一手持手机。
- 用户分别指定表情和动作时，以用户选择为准；只有搭配明显冲突时才提醒用户。

## 人物提示词写法

- 身份句只出现一次：“参考图1的人物五官特征，保持人物一致性和真人质感，真人半身出镜。”
- 身份句之后直接写具体表情、人物位置、身体方向、左右手动作和视线方向。
- 默认保留参考图1中的主要服装类型、颜色和个人形象风格；用户明确要求换装时，以用户要求为准。
- 优先使用“人物右手抬起，食指指向左上标题”这类正向目标描述，不在最终提示词里反复写“不要复制原动作”“不是编辑底图”“重新生成整个人物”等防御性说明。
- “抠图”只用于描述最终视觉效果，写成“真人半身抠图式前景”，不要写成“重新生成后再抠图”。

## 背景来源与处理

### 用户提供背景或主题素材

- 把用户提供的图片作为参考图2，并明确其角色是“完整背景图”还是“产品、软件或结果素材”。
- 完整背景图：保留主体事件、空间或产品内容，裁切成全幅 `3:4`。
- 产品、软件或结果素材：保留可识别的主题主体，将其自然融入一个全幅场景，不能做成悬浮卡片、圆角窗口或独立 UI 组件。
- 只做简单处理：统一色调、增强对比、适度锐化或景深、压暗上方标题区、清除原图文字和水印。
- 不把背景图装进电脑屏幕、手机框、圆角卡片或胶片框。
- 参考图中的点赞数、播放量、平台 UI 和角落数据只用于判断色调或表情，全部忽略，不得带入成图。

### AI 生成背景

- 根据主题生成一个明确的全幅场景，优先用单一主场景而非拼贴。
- 上方预留可压暗的标题区域，中下区保留主题主体，右下角为真人抠图留出空间。
- 背景不得生成文字、Logo、水印、UI 面板或装饰图标。

## 交互步骤

信息缺失时按顺序、一次一问：

1. **主题**：请提供主题、脚本摘要或想表达的结果。
2. **背景来源**：
   - 1）上传一张完整背景图，裁切为全幅背景；
   - 2）上传产品、软件或结果素材，将其自然融入全幅场景；
   - 3）由 AI 根据主题生成；
   - 4）交给模型判断。
3. **标题**：用户没有标题时给3组候选；主标题优先 4–12 字、2–3 行可拆分。
4. **副标题**：
   - 1）不要副标题；
   - 2）使用用户提供的副标题；
   - 3）根据主题生成一句 6–16 字副标题。
5. **强调色**：
   - 1）蓝紫科技；
   - 2）荧光绿色；
   - 3）渐变亮蓝；
   - 4）根据背景自动选择。
6. **人物表情**：
   - 1）自然微笑；
   - 2）张嘴震惊；
   - 3）认真讲解；
   - 4）疑惑思考；
   - 5）兴奋推荐；
   - 6）自信坚定；
   - 7）无奈吐槽；
   - 8）根据标题自动选择。
7. **人物动作**：
   - 1）指向左上标题；
   - 2）双手点赞；
   - 3）双手打开讲解；
   - 4）一手持手机、一手讲解；
   - 5）托腮思考；
   - 6）举拳自信；
   - 7）摊手无奈；
   - 8）根据标题自动选择。
8. **人物**：最后按主 skill 的随机人像流程确定参考图1，不要求用户重复上传。

用户已经给足信息时跳过对应问题，直接输出。

## 验收清单

- 比例严格为 `3:4`，无任何外框。
- 没有左上、右上账号文字或角标。
- 只有标题、可选副标题、全幅背景、右下真人四类元素。
- 主标题占上半区 40%–48%，比风格1明显更大。
- 主标题必须与绿色确认版保持同一字体骨架：超大极粗、硬边切角、字形轻微前倾、黑色超厚连续描边和右下硬投影；配色变化不得改变字体。
- 标题只有 `2°–5°` 轻微倾斜，没有明显对角线角度。
- 人物固定右下角，整体宽度约 42%–52%、高度约 42%–52%，脸部清晰且未遮挡标题；不得小于用户确认的左侧参考比例。
- 人物五官特征、身份和真人质感与参考图1一致，表情与动作符合本次指定要求。
- 左右手、手指、肩膀和手持物结构自然完整，表情与动作语义一致。
- 主要服装类型、颜色和个人形象风格默认延续参考图1，但服装结构与褶皱适配新动作。
- 只使用一套强调色：蓝紫、荧光绿或渐变亮蓝。
- 没有电脑框、手机框、卡片、按钮、机器人或碎片化装饰。
- 没有点赞数、播放量或平台 UI。
